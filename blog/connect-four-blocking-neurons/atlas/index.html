Every neuron, by layer

The model reads a game as a list of column numbers and has 6 layers of 1,024 neurons. Each neuron has two sides, a positive and a negative pole, which usually mean different things. Each square is one neuron, coloured by the theme of the side that matches a game concept best. Click a square to open it, or set up a board and watch every neuron respond.

How to read this page
  • Rows are layers. Layer 0 sees the moves first; layer 5 is the last before the model picks a column. Each small square is one neuron, 1,024 per layer.
  • Colour (with "Theme" selected) is the kind of game concept the neuron matches best, such as a single cell, a threat or the game phase. Brighter means a closer match. Grey neurons match none of our 659 concepts well, which is most of them.
  • The buttons change what the colour shows. "Described by the agent": the neurons an AI agent wrote a description for (160 descriptions in all). "Blocking circuit": the 53 neurons that carry the vertical block (the layer-5 ones are the column alarms). "Live board": set up a position and see how strongly every neuron fires on it right now.
  • Hover a square for a one-line summary; click it to open the neuron's page.

A good first stop: choose "Blocking circuit", then click one of the bright squares in layer 5.

Brightness: how strongly each neuron fires on this board, against its own firing threshold. Stones alternate; the player to move, the other.

A map of all 12,288 poles

Every pole is placed by what the board looks like when it fires (which cells hold the mover's stones, the opponent's, or nothing, compared with usual), so poles that read similar board patterns sit together. Colour is the theme of the concept it matches best; grey dots match none well. Scroll or pinch to zoom, drag to move, click a dot to open it.

How to read this page
  • Each dot is one side of a neuron. A neuron can fire strongly in the positive or the negative direction, and the two sides usually mean different things, so the 6,144 neurons give 12,288 dots.
  • Dots close together fire on similar-looking boards (which cells hold whose stones). Only nearness means something: the distance between far-apart groups and the directions of the axes do not.
  • Colour is the kind of concept the dot matches best; grey dots match none well. Labels name the most common concept in each region, with the column it is about.
  • Scroll or pinch to zoom, drag to move, click a dot to open its page. The search box above highlights matching dots.

How to read this page
  • Each card is one side of a neuron (L5 N344+ is layer 5, neuron 344, positive side). The sentence is the AI agent's description if it wrote one, otherwise the exact concept it matches best.
  • Agent F1 scores how well the agent's rule predicts when the neuron fires, on games the agent never saw. Concept F1 scores the closest exact concept the same way. Both run from 0 to 1: above 0.5 is a good match, below 0.3 a weak one.
  • The sets. "Described by the agent": every description from the agent runs. "Blind test": the 20 key circuit neurons and 20 look-alike decoys, sorted by how well the agent's rule picked out a block. "Vertical-block circuit" and "Column alarms": the neurons that carry the block.

Concept labels come from 659 exact game concepts (F1 on held-out games); agent descriptions from three pre-registered studies (120 neurons, then a blind test on 20 circuit neurons and 20 decoys). Columns and rows are numbered from 0. Part of An AI Agent Found Most of the Neurons That Block a Connect Four Threat.
